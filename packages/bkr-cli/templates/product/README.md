# {{displayName}} brand kit (program or product)

![Colors](tokens/exports/svg/palette.svg)

Child brand kit for **{{displayName}}**, part of the **{{parentBrandId}}** brand
family. It follows the [Brand Kit Repository (BKR)](https://github.com/Good-Heart-Tech/Brand-Kit-Standard)
standard, spec 0.2.

The parent kit owns the main colors and logo. This kit only adds what is
different about {{displayName}}, such as a program name, tagline, or one accent
color.

## Start here

- **See the brand:** open `tokens/exports/html/brand-at-a-glance.html` in any browser.
- **Finish the kit:** search for `TODO(bkr)` and replace each one.
- **Parent colors:** tokens marked `inheritsFrom` must match the parent kit. Check
  with `bkr validate --parent ../path-to-parent-kit`.

## Commands

```bash
bkr export --all
bkr digest
bkr validate --parent ../parent-kit
```
