# Partner-public profile (optional)

When `profiles.partnerPublic` is enabled, list paths safe to mirror externally
in `brandkit.yaml` → `publication.includedPaths`.

Suggested partner bundle:

- `assets/logo/mark.svg`
- `tokens/exports/dtcg/`
- `tokens/exports/css/variables.css`
- `copy/messaging.md` (short boilerplate only)
- `visual/logo.md` (usage rules)

Never include unreleased campaigns, internal naming drafts, or licensed fonts
without explicit redistribution rights.
