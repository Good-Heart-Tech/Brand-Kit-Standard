# Naming

- **Legal name:** Acme Labs, Inc.
- **Everyday name:** Acme Labs (never "Acme" alone, never "ACME")
- **Products:** Title Case with the org name on first mention, for example
  "Acme Docs" then "Docs"

## Do not

- Use "Inc." outside legal documents and contracts
- Invent product names before they are approved in this file

This file can include internal or draft names, so it is never shared outside
the organization.
