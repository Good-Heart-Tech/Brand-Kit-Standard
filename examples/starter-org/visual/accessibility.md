# Accessibility

- Meet WCAG 2.2 AA: 4.5:1 contrast for normal text, 3:1 for large text and
  interface parts.
- `bkr validate` checks every pair in `validation.contrastPairs`, in both the
  light and dark themes. The results table is on the brand-at-a-glance page.
- Do not use color alone to show meaning; add an icon or a word.
- Keep visible focus rings on every interactive element (use `primary`).
- Every image needs alt text; decorative images use empty alt text.
