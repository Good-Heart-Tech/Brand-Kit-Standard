# Palette usage

Normative hex values live in `tokens/colors.bkr.json`. Regenerate CSS with
`bkr export --css`.

## Defaults

- Page: `surface`
- Headings: `ink`
- Body: `body`
- Primary actions: white label on `primary`

## Do not

- Fill large backgrounds with `primary`
- Use `accent` for small text on white
