# Typography

Fonts live in `tokens/typography.obks.json`.

- Headings: `heading` font, `bold`, `tight` line height
- Paragraphs: `body` font, `regular`, `normal` line height
- Code and numbers in tables: `mono`

Inter and JetBrains Mono are free under the SIL Open Font License, so partners
may download them from Google Fonts. We do not ship font files in this kit.
