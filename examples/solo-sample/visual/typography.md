# Typography

Fonts live in `tokens/typography.bkr.json`.

| Use | Font | Weight | Size |
|-----|------|--------|------|
| Page and section headings | `heading` (Cormorant Garamond) | `bold` | `heading`, `tight` line height |
| Intro paragraphs and pull quotes | `heading` (Cormorant Garamond) | `regular` | `large` |
| Body text, proposals, invoices | `body` (Karla) | `regular` | `base`, `normal` line height |
| Buttons and invoice totals | `body` (Karla) | `bold` | `base` |
| Captions and photo credits | `body` (Karla) | `regular` | `small` |

- Cormorant Garamond is elegant but delicate. Use it at `large` size and above;
  never for small text or long paragraphs.
- Karla carries everything practical: paragraphs, prices, dates, and forms.
- Both fonts are free under the SIL Open Font License, so printers and clients
  may download them from Google Fonts. No font files are shipped in this kit.
- If a font is missing, the fallbacks are Georgia for headings and the system
  font for body text.
