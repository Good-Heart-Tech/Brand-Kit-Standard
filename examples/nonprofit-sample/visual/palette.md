# Colors

See every color, and which pairs are readable, in
`tokens/exports/html/brand-at-a-glance.html`.

## Defaults

- Page background: `surface` (warm off-white)
- Headings: `ink`
- Paragraphs: `body`
- Donate and volunteer buttons: `onPrimary` text on `primary`
- Links: `link`
- Highlight bands and flyers: `harvest`, with large `ink` headings only

## Do not

- Put small text on `harvest`
- Put `harvest` text on white (it is too light to read)
- Use red for donation asks (it reads as an emergency)
