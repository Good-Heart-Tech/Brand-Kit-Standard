# Colors

Official values live in `tokens/colors.bkr.json` (light) and
`tokens/themes/dark.bkr.json` (dark). See them all, with contrast results, in
`tokens/exports/html/brand-at-a-glance.html`.

## Defaults

- Page background: `surface`
- Cards, service tiles, and table stripes: `subtle`
- Headings: `ink`
- Body and form text: `body`
- Buttons and the page header bar: `onPrimary` label on `primary`
- Links: `link`, always underlined
- Success and confirmation messages: `onPrimary` text on `success`, with a
  check mark icon and the word "Done" or "Submitted"
- Emergency and warning banners: `onAlert` text on `alert`, with a warning
  icon and the word "Alert" or "Warning"

## Dark theme

The dark theme changes `surface`, `subtle`, `ink`, `body`, `primary`, and
`link`. Use the CSS variables and it switches automatically. `alert`,
`onAlert`, and `success` stay the same, so alerts look the same in every theme.

## Do not

- Use `alert` gold for text, icons on white, or buttons; it is a banner
  background only
- Put white text on `alert` gold
- Use color alone to show meaning (for example, a green field for "valid");
  always add an icon and words
- Fill large page areas with `primary`
- Add department colors; every department uses this palette
